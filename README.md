# Hero Homes Lucknow - Single Page Landing Page

High-converting single page landing page for **Hero Homes Lucknow** (Premium Plots & Villas on Kanpur-Lucknow Highway).

## 🚀 Features
- **Official Hero Homes Branding**: Integrated high-density logo and brand red/black color palette.
- **Lead Capture & Auto Popup**: 2-second timed auto-popup and modal inquiry forms.
- **Email Dispatch**: Submissions automatically email details to `digitaldasofficial@gmail.com`.
- **Conversion Tracking**: Dedicated `thank-you.html` page ready for Google Ads & Meta Pixel conversion tracking.
- **Mobile Responsive**: Streamlined header with instant WhatsApp and Enquire triggers.
